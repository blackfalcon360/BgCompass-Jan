# BgCompass

A **live compass wallpaper** for Android.

- Your own image as the background (picked inside the app)
- One line of text just above the fingerprint area: **degrees + direction** in a single font size, e.g. `245° SW` — position adjustable with a slider
- Works on the home screen and, on phones that allow live wallpapers there, on the lock screen
- Sensors are used only while the wallpaper is visible

Package: `bgcompass.blackfalcon.jan` — **By: Black Falcon**

## Use
1. Install the APK and open **BgCompass**.
2. Tap **Choose background image**, then move the **text position** slider so it sits above your fingerprint.
3. Tap **Set as live wallpaper** and choose Home / Lock / Both.

Phone flat → direction of the top of the phone. Phone upright → direction the back of the phone faces.

## Build
Push to GitHub — the **Build APK** workflow runs automatically.
Open **Actions → latest run → Artifacts → BgCompass** to download `BgCompass.apk`.
